# Interface Contracts

Function signatures, type definitions, and component/API contracts — so a session can work
without opening source files. Keep these in sync when signatures change.

> Empty for now — contracts are added as the codebase grows (starting in Phase 0/1).

## Planned contracts (examples)

- `db-models.md` — Prisma models and their typed shapes.
- `api-routes.md` — server routes/actions: method, auth, input (Zod), output, audit.
- `components.md` — UI components by domain: name, purpose, props.
- `lib-utilities.md` — shared helpers (validation, parsing, diffing, publish/import).
