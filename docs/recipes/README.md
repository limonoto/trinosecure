# Recipes

Step-by-step checklists for common multi-file tasks — which files to change, in what order.
Read the matching recipe **before** starting a task; add a new recipe whenever a repeatable
multi-file pattern emerges.

> Empty for now — recipes are added as the codebase grows (starting in Phase 0/1).

## Planned recipes (examples)

- `add-rule-type-editor.md` — add a UI editor for a `rules.json` rule type.
- `add-config-artifact.md` — support a new managed config artifact (DB type + import/export + publish).
- `add-i18n-key.md` — add a translation string (en first).
- `add-api-route.md` — add a Next.js server route/action with auth + validation + audit.
